# MP3_Fourier_Project
This is a project attempting to determine a good way of determining guitar timbre from its recorded sound signals. There are many issues with it, including some about precise pitch detection (which is an issue because, while algorithms like autocorrelation generally determine it, they are often a few hertz off, leading to larger and more devestating gaps at higher harmonics). Another such issue is that this does not record in real time, which will hopefully be fixed in a later version of this. For the moment however, this is the general idea of the software, with issues to be fixed in a future program.
